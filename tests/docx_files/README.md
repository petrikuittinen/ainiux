# DOCX fixtures

`minimal.docx` is generated by Ainiux's deterministic writer from `supported.md`.
The adjacent `minimal.md` records its exact normalized extraction. The other positive
fixtures were exported through LibreOffice's Office Open XML Text filter from
the HTML sources under `sources/`. Adjacent `.md` files are exact extraction
goldens. `manifest.json` records producer versions and expected warnings.

Small malformed packages and low-level ZIP/XML shapes are built directly in
`tests/unit/docx/test_docx.cpp`, keeping the bytes under test reviewable without
requiring Python, LibreOffice, or another office package at test time. The
checked-in binaries make the normal test suite dependency-free.
