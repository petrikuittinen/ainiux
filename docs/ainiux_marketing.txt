Ainiux — terminal chat, editing, and local agent workflows in C++17.

Short description

Ainiux is an open-source command-line and terminal client for OpenAI and OpenAI-compatible APIs. It includes scriptable chat, a saved-thread TUI, a standalone editor with optional AI assistance, project-local agent workflows, conversion, benchmarks, and judge grading. Ubuntu x86-64 and ARM64 are the tested baseline; the POSIX-oriented design may work more widely but is not guaranteed.

Facebook / LinkedIn

Ainiux brings several model workflows into one terminal application: scriptable prompts, a full-screen chat library, a standalone editor, explicit project-agent modes, document conversion, and benchmark grading. It works with built-in cloud and local provider profiles or a custom OpenAI-compatible endpoint. The project is open source and built in C++17 with libcurl, SQLite, POSIX terminal APIs, and a Makefile. Compatibility and model capabilities vary, so consult the provider and platform notes before deployment.
